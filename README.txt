客户管理助手 PWA V5.13.0｜国网中标行情版

新增第 4 个页签「中标行情」：把国家电网组合电器中标结果做进 PWA，拜访前可直接查企业份额。

- 数据来源：电能革新（微信公众号）公开发布的中标分析文章，经新浪财经等门户同步转载。
- 覆盖范围：2026 年输变电项目变电设备（含电缆）公开招标采购的「组合电器」共 4 期、99 条中标记录、29 家企业。
  不含特高压 1000kV 组合电器，不含开关柜。
- 数据更新方式：打开页面时自动读取仓库根目录的 market.json（同源、网络优先策略，每次打开拉最新版）；
  断网或本地打开时自动退回 index.html 内置快照，功能不中断。
- 与客户库联动：中标企业若与你的客户库模糊匹配命中（相似度 ≥0.55），列表中显示 📍 标记，
  点击可直接跳到该客户详情；支持「只看我的客户」筛选。
- 口径：期次按电能革新「第 N 次变电设备招标」归并，与国网官方采购批次号并非一一对应。
  各企业金额逐条相加与公告合计存在 ≤1 万元取整尾差，占比以榜单合计为分母。
- Service Worker 缓存升级为 V5.13.0，部署后会清理旧 crm-pwa-* 缓存。
- 本次未改动任何存储键名（mobile_crm_v1_data / mobile_crm_v1_meta 等），已有客户数据完整保留。

客户管理助手 PWA V5.9

- 基于 V5.6 旧数据库兼容版升级，保持公开初始数据库为 0 客户 / 0 联系人 / 0 拜访。

- 保留 V5.6 的连续语音自动续听逻辑、客户/联系人候选、附件、拜访报告、看板和旧数据库兼容导入。

- app.js 仍不包含任何客户资料。
