客户管理助手 PWA V5.9

- 基于 V5.6 旧数据库兼容版升级，保持公开初始数据库为 0 客户 / 0 联系人 / 0 拜访。
- 新增个性语音学习：客户误识别/简称、联系人误识别、短词纠错会在本机自动记忆。
- 新增常用专业术语规范：CUD / CUDD / CUX / LSS / GIS / GIL / SST / MC。
- 在语音确认页修正沟通内容中的短词后，会提取局部改动作为纠错记忆，避免死记整句话。
- 学习数据保存在当前服务器域名对应的浏览器 localStorage；同一域名重新部署新版后继续保留。
- 保留 V5.6 的连续语音自动续听逻辑、客户/联系人候选、附件、拜访报告、看板和旧数据库兼容导入。
- Service Worker 缓存升级为 V5.9，部署后会清理旧 crm-pwa-* 缓存。
- app.js 仍不包含任何客户资料。


V5.8 新增：看板统计卡可点击筛选；筛选列表支持已完成、延期、等待客户、待跟进；可查看拜访详情；提供返回看板按钮。


V5.9 新增：
- 语音只在“语音录入”页面前台持续监听；切到看板/客户库/筛选页、网页进入后台、锁屏或最小化时自动停止。
- 保存一条语音拜访后自动停止监听并清空识别文本、确认区和本次附件引用。
- 保存后不自动跳走，显示“新增一条拜访 / 查看刚保存的客户 / 返回跟进看板”三个选择。
- 沟通内容与待办在确认页被手动纠正后，会学习其中的短词差异，下一次优先自动纠正。
