客户管理助手 PWA 测试版

包含：
- Safari/PWA 主屏幕安装
- 原有客户/联系人/拜访记录
- 旧版 JSON 主数据直接导入
- S/A/B/C 重要程度
- 跟进日期时间、待跟进/等待客户/已完成
- 看板：逾期、今天、未来7天、等待客户
- 语音入口：浏览器支持 Web Speech 时直接识别；否则可用 iPhone 键盘麦克风
- 语音后先提取、候选确认，再保存
- JSON/CSV 导出
- Service Worker 离线缓存

注意：
1. PWA 必须部署在 HTTPS 网站上，不能直接点 index.html 获得完整 PWA 能力。
2. 此测试版尚未接服务器 Web Push，因此 App 完全关闭时不保证按时后台通知。
3. 语音“信息提取”目前是本地规则 + 现有客户库匹配，不是云端大模型。
4. 旧 JSON 的原字段不会被破坏；新字段缺失时按 B/待跟进/空跟进时间处理。
