客户管理助手 PWA V5.17.0｜语音也能关联项目版

修一个用起来最别扭的问题：语音录入记完拜访，没法挂到项目上。

- **语音录入确认卡新增「关联项目」**。以前这块只在拜访编辑器里有，走语音这条路
  记下来的拜访永远挂不到项目，项目详情里也就看不到这条记录。
  现在和编辑器一致：可点选已有项目、可「＋ 新建项目」、可设为「不关联」。
- **「关联项目」的位置提到前面**：编辑器里排在「联系人」之后、「办公地 / 沟通内容」之前，
  语音卡里排在「拜访日期」之后、「沟通内容」之前。以前排在最后，手机上要滚到底才看得见。
- **项目关联不会串客户**：在语音卡里选了 A 客户的项目，再把客户改成 B，
  原来那个项目关联会自动清掉（并给出提示），不会把 A 的项目记到 B 名下。
  保存时若项目不属于该客户，一律拒绝写入（projectId 存空串，不是 undefined）。
- **新建项目会查重**：在拜访编辑器 / 语音卡里「＋ 新建项目」时，如果该客户名下已经有同名项目，
  会问你是「复用已有项目」还是「仍然新建」，避免同一个项目被建出好几条。
- **点候选人名时不再吞掉手打的内容**：以前点客户 / 联系人候选按钮会重绘整张卡，
  你刚敲进去的沟通内容、待办会被重置掉；现在重绘前会先把当前输入收回来再重画。
- 修复：以前用「新建客户 + 记一条拜访」这条路建出来的新客户**没有 projects 字段**
  （老客户有、新客户没有），导致刚建的客户进详情页时项目区状态不对。现已补齐，
  新拜访也一律带 projectId 字段。
- 兼容：老数据不受影响，存储键名未变。

客户管理助手 PWA V5.16.0｜附件零泄漏与存储自检版

修一个会慢慢吃掉手机空间的隐形问题：以前删客户 / 删拜访 / 删项目，附件只是从记录里
消失，文件本身还留在浏览器存储里，而且没有任何入口能看到它们。这一版把所有删除路径接通了。

- **删除客户、删除拜访记录、删除项目时，会同时删掉这些记录里本地附件的那份文件**
  （以前只删了引用，文件会永远留在存储里，越用越占地方）。
- 语音录入中途放弃（点了「开始新的拜访」、或没保存就离开）时，草稿里已经添加的照片 /
  文件也会一并清理；如果这条草稿已经保存成了拜访记录，附件仍然保留，不会被误删。
- 删除前的确认框会明确写出「这次会一起移除 N 个附件」，删之前心里有数。
- 客户库工具栏新增 **「存储自检」**：
  · 先只做体检、不动任何数据。报出：客户 / 拜访 / 项目数、记录引用的附件数、
    本机附件库实际文件数与总大小、其中多少个已经没有记录引用（孤儿附件）、
    多少个引用在本机找不到文件（换过设备、或恢复备份时没带附件），以及浏览器给的存储额度。
  · 明确确认后才清理孤儿附件，并告诉你清理了几个、释放了多少空间。
- 建议每隔几个月点一次「存储自检」。换手机、清浏览器缓存之前，先点「完整备份（含附件）」。

客户管理助手 PWA V5.15.0｜项目进看板版

新增：看板首页直接看到手上的项目，不用再逐层点进客户库。

- 看板「今天最该处理」下方新增「项目」区块，把所有客户名下的项目摊平汇总。
- 顶部一排可点筛：全部 / 跟进中 / 已投标 / 已中标 / 需要关注，每个都带数量；
  「需要关注」（漏跟的项目）有数量时标红，一眼看出该补哪个。
- 项目卡显示：项目名称、所属客户、项目编号、状态色标、附件数、关联拜访数、最近一次拜访日期。
- **需要关注口径**：状态为「跟进中」或「已投标」，且**从未有过关联拜访**、或
  距最近一次关联拜访已满 **30 天**（阈值常量 DASH_PROJ_STALE_DAYS，可改）。
  命中的卡片额外显示 `⚠ N 天没动静` / `⚠ 从未拜访`。
- 排序：需要关注的在最前 → 已投标 → 跟进中 → 已中标 → 暂停 → 已丢单；同组内越久没动越靠前。
- 每个项目卡两个动作：
  · **打开项目** —— 跳到项目详情（附件、图纸、关联拜访都在那）。
  · **记一次拜访** —— 直接开拜访编辑器，客户和项目都已预选好，保存后自动回看板。
    这是外勤场景里最省事的一条路径：看板上一眼看到该跟的项目 → 点一下就开始记。
- 项目列表默认显示 6 个，超过时给「展开全部 N 个 / 收起」。
- 从看板跳进项目详情后，左上角「返回」直接回看板（不会退回客户库搜索页）。

客户管理助手 PWA V5.14.0｜客户项目库版

新增：每个客户名下有「项目」，拜访与项目可以互相关联。

- 客户详情新增「项目」入口（联系人 / 项目 / 拜访报告 三格）。
- 项目字段：项目名称、项目编号（备注名）、状态（跟进中 / 已投标 / 已中标 / 已丢单 / 暂停）、备注说明。
- 项目附件：图纸、照片、招标文件等本地文件，以及网盘 / 官网链接。与拜访附件共用同一套本机
  IndexedDB 存储（crm_attachments_v1），可打开预览、可删除。
- 双向关联：一个项目可以关联多条拜访；一条拜访只挂一个项目。
  · 拜访编辑器里新增「关联项目」选择区，可点选、可「＋ 新建项目」、可设为「不关联」。
  · 拜访详情显示「所属项目」，可直接跳到项目。
  · 项目详情列出关联的拜访，支持「关联已有拜访」（可多选）、「新建拜访并关联本项目」、「解除关联」。
  · 项目列表卡片显示：状态、附件数、关联拜访数、最近拜访日期。
- 客户库搜索现已覆盖项目名称 / 编号 / 备注 / 状态。
- **附件备份补全**：工具栏新增「完整备份（含附件）」与「恢复完整备份」。
  以前的「备份当前数据库」只导出客户数据，本机附件（照片、图纸）不在里面；现在可以打包成
  一个 JSON 完整带走了。换手机、清缓存前请务必用这个入口备份。
- 修复：iOS 上点「保存并导出数据」时，系统分享面板可能被拒（原因是 await 持久化存储请求
  消耗掉了用户手势）。现在改为同步发起，分享面板可正常调出。
- 兼容：老数据自动补齐 projects / projectId 字段，存储键名未做任何改动
  （mobile_crm_v1_data / mobile_crm_v1_meta 等），已有客户、联系人、拜访记录完整保留。
- 顺手修掉两个老问题：
  · 页签高亮丢失：页签按钮 id 是 tabDB，而切换逻辑拼出来的是 tabDb，导致点「客户库」时
    该页签不会高亮（其它页签的高亮又已被清掉，看起来像"没有选中项"）。现已改为显式 id 映射。
  · 拜访编辑器里点「＋ 新建项目」，对还没有任何项目的客户会失败（内部传了越界下标 -1）。
- Service Worker 缓存升级为 V5.14.0，部署后会清理旧 crm-pwa-* 缓存。

客户管理助手 PWA V5.13.0｜国网中标行情版

新增第 4 个页签「中标行情」：把国家电网组合电器中标结果做进 PWA，拜访前可直接查企业份额。

- 数据来源：电能革新（微信公众号）公开发布的中标分析文章，经新浪财经等门户同步转载。
- 覆盖范围：2026 年输变电项目变电设备（含电缆）公开招标采购的「组合电器」共 4 期、99 条中标记录、29 家企业。

  断网或本地打开时自动退回 index.html 内置快照，功能不中断。

  点击可直接跳到该客户详情；支持「只看我的客户」筛选。
- 口径：期次按电能革新「第 N 次变电设备招标」归并，与国网官方采购批次号并非一一对应。
  各企业金额逐条相加与公告合计存在 ≤1 万元取整尾差，占比以榜单合计为分母。
- Service Worker 缓存升级为 V5.13.0，部署后会清理旧 crm-pwa-* 缓存。
