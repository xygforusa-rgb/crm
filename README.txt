客户管理助手 PWA V5（免费本地智能版）

核心升级：
1. 本地智能客户识别：客户名/简称/模糊名称/地区/联系人联合评分。
2. 自动学习：当语音把客户名识别错、你手动选择或纠正后，本机会记住这个叫法，下次优先匹配。
3. 联系人反向识别客户：客户名称不准时，可利用已有联系人辅助锁定客户。
4. 日期、跟进时间、重要程度、待办自动提取。
5. 所有数据库字段继续支持单项修改；附件继续使用 IndexedDB 本地保存和预览。
6. 不使用收费 AI API，不产生模型调用费用；数据默认保存在当前浏览器设备。
7. PWA 网络优先更新，离线时回退缓存。

部署：解压后把全部文件覆盖上传到 GitHub Pages 项目根目录。
注意：浏览器语音转文字能力由设备/浏览器提供；V5 的“理解和匹配”逻辑本身在本机执行。
