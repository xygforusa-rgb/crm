客户管理助手 PWA 测试版 V4

新增：
- 拜访记录可添加多个本地文件/照片
- 可添加网页、iCloud/网盘共享等外部链接
- 本地文件实际保存在浏览器 IndexedDB 附件库，主数据库只保存附件引用
- 客户库中可打开、增加、删除附件/链接
- 完整备份（JSON，含附件内容）与完整恢复
- 原“主数据 JSON”导入导出继续保留，兼容旧数据库

说明：
- 浏览器网页无法可靠永久保存 iPhone“文件”App里的任意本地路径，因此选择的本地文件会复制进 CRM 的本地附件库。
- 外部文件如需保持由系统/iCloud管理，推荐在 CRM 中保存其可访问共享链接。


V4.1 更新（2026-09-03）：修复 PWA 在手机端长期显示旧版本的问题；Service Worker 改为版本化缓存、自动清理旧缓存、立即接管，并对页面采用网络优先策略。
